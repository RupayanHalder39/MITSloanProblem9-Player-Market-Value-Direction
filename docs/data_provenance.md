# Data provenance and availability

The analysis combines a published player-valuation history with match-level football performance records. The broader panel contains 8,433 player-decision events for 1,132 players from July 2022 through June 2025; the locked Championship test contains 752 valuation events from 606 players.

Raw and row-level data are not distributed in this repository. The source materials reviewed for this release did not establish public redistribution rights for those records. The public package therefore contains only aggregate result tables that do not identify players.

An authorized researcher can reconstruct the analysis by obtaining lawful access to equivalent valuation and match-performance sources, creating one row per player valuation date, restricting all features to pre-valuation information, and applying the definitions in `methodology.md`. Exact reconstruction also requires the project's source-specific entity resolution and temporal alignment rules.

Software screenshots shown in the final paper are not published as standalone repository assets because separate redistribution authorization was not documented.
